Content Editor

Add a new person to the People directory. This creates a new branch and opens a Pull Request — nothing is written to main directly.

Needs write access to this repo. Your token is only kept in this browser tab and is never sent anywhere except api.github.com.
Don't have a token? Go to GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens, and grant "Contents: Read and write" on this repo.
